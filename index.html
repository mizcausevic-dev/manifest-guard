Catch insecure Kubernetes manifests before they merge.

Paste YAML or open a file. 18 rules check for privilege escalation, host access, leaked secrets, missing limits and probes, and fragile rollouts. Results run locally in your browser. The same engine ships as a CLI that writes SARIF for GitHub code scanning.

Use it in CI

The same rules engine runs in Node 20+ with no dependencies to install. Exit code 1 means findings at or above --fail-on, and 2 means bad input.

node bin/manifest-guard.mjs k8s/*.yaml
node bin/manifest-guard.mjs --format sarif --fail-on none k8s/*.yaml > manifest-guard.sarif
node bin/manifest-guard.mjs --disable MG002,MG008 --fail-on warning deploy.yaml

Upload the SARIF file with github/codeql-action/upload-sarif@v4 to see findings inline on pull requests.
